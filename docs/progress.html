Chabruh

Build tracker for the 2D surf game. Slow, sunny, no bad guys. Nine steps, each one checked before the next begins.

How to use this page

1. Start. Open a fresh Claude context in the project folder and paste a step's Start prompt. Claude posts a short plan first. Say OK.
2. Verify. Claude gives you a preview link. Work through the checklist on desktop and phone. Ticks are saved in this browser.
3. Close it out. Happy? Paste Done. Not quite? Paste Tweak and say what you saw. Claude updates the status of the step in this file.

The plan

Why these choices

Godot 4.7One project exports to web now and Android later. Built-in 2D shaders and particles, text-based scenes Claude can edit, and a command line that can test and export headlessly.
Flat-shaded 2D, not pixel artOver the Hill is soft, flat-shaded shapes in warm hazy light, not pixels. Our version is vector-style layers with purple shadows and an 80s sunset palette. Tell me early if you would rather have pixel art. It changes steps 2, 3, 4 and 6.
A parametric wave, not sprites or a fluid simReal waves are a few numbers (size, steepness, peel angle) swept along a crest. A small model computes the shape, a shader draws it, and particles add spray. It scales from a ripple to a barrel, the surfer can ride its exact surface, and it is cheap on a phone. Wave sprites cannot change size or react to the surfer, and a fluid simulation is too heavy and too hard to art-direct.
Procedural art firstEverything is drawn with code and shaders, so Claude can build and tune it without art tools. Hand-made sprites can replace pieces later.
No fail stateA wipeout is a soft tumble and a paddle back. There is no score, timer, or game over, in line with the vibe.
Preview, then liveEach step is deployed to a temporary Firebase preview link for checking on your phone. It only goes to the live site when you say Done.

After step 9: design iteration

  • Sharpen the look: more palette moods, a pixel or dither toggle, hand-drawn sprites swapped in for procedural ones.
  • More breaks and boards, new wave shapes, costumes.
  • A photo mode (the Over the Hill style of taking a quiet moment).
  • Android build.
